One line, 200 characters, roasting a gadget I use every day — my entry for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty. The program writes a single original roast to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

## The roast

> My phone's alarm snoozes itself after nine minutes, like it's the one who needs more sleep — then blames me for being late.
